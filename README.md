# 🚀 TypeFlow

**TypeFlow** is a modern, premium typing-speed test web application built with **HTML, CSS, and Vanilla JavaScript**. It combines a sleek glassmorphism-inspired interface with real-time performance analytics to deliver a professional typing experience directly in the browser.

Designed without frameworks, TypeFlow demonstrates how powerful and polished web applications can be created using core front-end technologies alone.

## ✨ Features

### ⌨️ Typing Experience

* Random paragraph generator with 20+ curated typing passages
* Daily Challenge mode
* Automatic test start on first keystroke
* Multiple test durations (30s, 60s, 120s)
* Difficulty levels:

  * Easy
  * Medium
  * Hard
* Real-time character-by-character validation
* Full backspace support
* Smooth active-word tracking
* Animated typing caret

### 📊 Real-Time Analytics

* Words Per Minute (WPM)
* Accuracy Percentage
* Consistency Score
* Progress Tracking
* Characters Typed
* Correct Characters
* Incorrect Characters
* Live Streak Counter

### 🏆 Achievement System

Earn badges based on typing performance:

| Badge        | WPM Range |
| ------------ | --------- |
| Beginner     | < 30      |
| Intermediate | 30 – 55   |
| Expert       | 55 – 80   |
| Master       | 80 – 100  |
| Grandmaster  | 100+      |

### 💾 Personal Records

Performance statistics are automatically saved using Local Storage:

* Best WPM
* Best Accuracy
* Total Tests Completed
* Total Typing Time

### 🎨 Modern UI/UX

* Glassmorphism design
* Dark Mode / Light Mode
* Responsive layout
* Smooth transitions and animations
* Focus Mode for distraction-free typing
* Mobile-friendly experience

### 🔊 Audio Feedback

* Synthesized keyboard click sounds
* Error sound feedback
* Fully offline using Web Audio API
* No external audio files required

### 📤 Export Results

Generate and download a personalized performance certificate as a PNG image.
